# Лабораторные работы по Unity (C#)

Учебный репозиторий, содержащий 3 лабораторные работы по разработке в среде Unity.

---

## Лабораторная работа №1: Катящийся шар

Разработка базовой механики катящегося шара с физикой, сбором предметов и усложнённым рельефом.

### Особенности:
- **Управление сферой:** на основе физических сил (`Rigidbody.AddForce`) относительно направления камеры.
- **3 составных уровня:** платформы на разной высоте, мостики, рампа для перелёта, Г-образная трасса, диагональный ветер, зоны ускорения (`BoostZone`) и замедления (`SlowZone`).
- **Следящая камера:** плавное перемещение через `Vector3.Lerp` (`LookAt`).

---

## Лабораторная работа №2: Пользовательский интерфейс

Полноценная система UI, связывающая уровни в единый игровой цикл с сохранением прогресса.

### Особенности:
- **Главное меню (`MainMenu`):** навигация и всплывающая панель помощи.
- **Экран загрузки (`LoadingScreen`):** фоновая асинхронная загрузка с прогресс-баром (`Slider`).
- **Выбор уровней (`LevelSelect`):** горизонтальная прокрутка (`ScrollRect` + `RectMask2D`), карточки-заглушки «Скоро...», заблокированные уровни.
- **Внутриигровое меню паузы (`PauseMenu`):** вызов по `Escape` с остановкой времени.
- **Система прогресса:** синглтон `GlobalData`, оценка прохождения (1–3 звезды) и авто-разблокировка.

---

Лабораторная работа №3: Редактор уровней

Автономный редактор трехмерных сцен с функционалом размещения, редактирования, сериализации и пользовательским интерфейсом.

### Особенности:
- **Палитра объектов:** динамическое считывание префабов из папки `Resources/` по категориям через компонент `Dropdown`.
- **Размещение со следованием за курсором:** объект привязывается к курсору мыши до клика ЛКМ (отмена на ПКМ).
- **Инспектор свойств объекта (InfoPanel):**
  - **Переименование:** редактирование имени через `InputField`.
  - **Вращение:** слайдер вращения по оси Y (0–360°).
  - **Подъём по вертикали:** слайдер изменения высоты Y (0–10 ед.).
  - **Перемещаемые окна:** плавающие панели с перетаскиванием за заголовок (`DraggablePanel`).
- **Выделение и коллизии:** подсветка выделенного объекта (жёлтый) и регистрация пересечений (красный).
- **Список объектов сцены:** динамическая левая панель со всеми установленными объектами.
- **Сериализация:** сохранение и загрузка сцены в формате **JSON** (`JsonUtility`).

│   ├── LoadingScreenController.cs # ЛР2: Загрузочный экран
│   ├── LevelSelectController.cs   # ЛР2: Выбор уровней
│   ├── PauseMenuController.cs     # ЛР2: Пауза

## Технологии и стек

- **Engine:** Unity 2022.3.62f3 LTS (Built-In Render Pipeline)
- **Language:** C#
- **Data Serialization:** JSON (`JsonUtility`)
- **UI System:** Unity UI (Canvas, ScrollRect, RectMask2D, Custom Draggable Panels)

---

## Инструкция по запуску

1. Откройте проект в **Unity 2022.3 LTS**.
2. Откройте сцену `Assets/Scenes/MainMenu.unity`.
3. Нажмите кнопку **Play**.
